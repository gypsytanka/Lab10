# Домашнее задание к работе 10
## Условие задачи 
Вариант 12. Составьте программу, которая для заданной пользователем фигуры, например трапеции, предлагает меню выбора одной из операций:
1) рассчитать площадь;
2) вывести определение фигуры;
3) нарисовать фигуру.
   
## 1. Алгоритм и блок-схема

### Алгоритм
1. Начало 
2. Задать исходные данные:
    + `a` - длина меньшего основания
    + `b` - длина большего основания
    + `h` - высота
3. Запустить цикл меню (показать варианты операций):
    + 1: Площадь трапеции
    + 2: Определение фигуры
    + 3: Рисунок трапеции
    + 0: Выход
4. Обработка выбора пользователя:
    + 1: `area_trapezoid(a, b, h)`
    + 2: `name()`
    + 3: `draw_trapezoid((int)a, (int)b, (int)h, symbol)`
    + 4: `break`
5. Повтор цикла:
    + Возврат к показу меню
    + Выход при выборе "0"
6. Вывести результаты расчетов с подстановкой всех значений в текст.
7. Конец
